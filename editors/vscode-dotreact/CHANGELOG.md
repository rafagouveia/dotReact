# Changelog

All notable changes to the DotReact VS Code extension are documented here.

## 0.2.0

- Resolve the checker from published and vendored DotReact projects.
- Support the current `app/` router while retaining legacy `src/pages/` navigation.
- Coalesce repeated validations and prevent concurrent checker processes per workspace.
- Open colocated `page.server.cs` loaders without scanning the entire backend.
- Add project-health status, validation output and documentation commands.
- Declare Workspace Trust and virtual-workspace limitations explicitly.
- Add a dedicated Marketplace icon and localized manifest metadata.

## 0.1.0

- Associate `.drx` files with TypeScript React language features.
- Add check-on-save diagnostics and C# loader CodeLens navigation.
